# CSDL - Cơ sở dữ liệu

Thư mục này chứa các thiết kế cơ sở dữ liệu và sơ đồ quan hệ thực thể (ERD) cho hệ thống ISAAP.

## Các tài liệu dự kiến
- Sơ đồ ERD (Entity Relationship Diagram)
- Tài liệu Đặc tả các bảng dữ liệu (Data Dictionary / Database Schema Spec)
- Các tập lệnh SQL khởi tạo và migrations
